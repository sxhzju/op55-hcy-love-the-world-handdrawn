# 华晨宇《好想爱这个世界啊》补全结尾版 · 手绘歌词视频

手绘线条 + 纸张质感的 3:4 竖版歌词动画（1080×1440，30fps，H.264）。

- **画面**：程序生成的纸张纹理（纤维、颗粒、晕影、横格线），所有线条经过低频抖动与双遍铅笔描边，每 4 帧重新抖动一次（手绘动画的 "line boil"）。
- **配图**：每条字幕按标点拆成分句，按字数分配时长，并按语义匹配一幅手绘插画；插画逐笔"画出"，随后水彩色块晕入，并带有待机动效。本片的分镜：

| 时间 | 歌词分句 | 画面 |
| --- | --- | --- |
| 0.76–2.80 | 想过离开， | 小人拎着行李走向地平线的小路 |
| 2.80–6.38 | 当阳光败给阴霾， | 乌云遮住太阳，雨中的小人（雨滴下落） |
| 6.38–11.99 | 没想到你会拼命为我拨开。 | 两只手把乌云推开，笑脸太阳露出、光芒旋转 |
| 11.99–14.47 | 曾想过离开， | 半掩的门透出光，小人在门口犹豫 |
| 14.47–17.93 | 却又坚持到现在， | 嫩芽从龟裂的土地里长出、轻轻摇摆 |
| 17.93–21.40 | 熬过了那些旁白。 | 漂浮的"闲言碎语"气泡，小人撑伞站定 |
| 21.40–24.55 | 那些姿态，那些伤害。 | 贴着创可贴的心，随心跳搏动 |
- **字幕**：完整保留 `subtitles.srt` 的原文与起止时间；手写字体逐字显现，自动换行/缩放保证不溢出，下方荧光笔划线。
- **音频**：原音从 0 秒起原速完整保留（原音文件不入库）。

## 目录

| 路径 | 说明 |
| --- | --- |
| `src/render.py` | 渲染器：Pillow 逐帧绘制（笔画 2× 超采样抗锯齿）→ 原始 RGB 管道送入 ffmpeg |
| `src/subset_font.py` | 从霞鹜文楷子集化出所需字形 |
| `subtitles.srt` | 字幕 |
| `assets/paper.png` | 纸张纹理 |
| `assets/fonts/` | 子集化字体 PaperHand Subset（基于 LXGW WenKai，SIL OFL 1.1，见 `OFL.txt`） |
| `build.sh` | 一键生成高清版与预览版 |
| `pyproject.toml` / `uv.lock` | 依赖与锁文件 |

## 构建

需要 [uv](https://docs.astral.sh/uv/) 与 ffmpeg。将原音放到 `original.wav` 后：

```bash
./build.sh            # 生成 op55-hd.mp4 与 preview.mp4
uv run python src/render.py --still 3 10 20   # 仅导出若干时间点静帧到 build/
```

成片发布于 GitHub Release。
